# Shelfie

A book management mobile app built with React Native and Expo.

## Features

- User authentication with Appwrite
- Create and delete books
- Fetch individual book records
- Dynamic routes with Expo Router
- Display books using FlatList
- Real-time updates using Appwrite Realtime
- Zustand for state management

## Tech Stack

- React Native
- Expo
- Expo Router
- Zustand
- Appwrite

## Getting Started

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Configure your Appwrite environment variables in a local `.env` file.
4. Start the development server:

   ```bash
   npx expo start
   ```

## Note

This project was built while following a React Native tutorial and is intended for learning purposes.
